# The Keeper's Light

One short text, written to intrigue the AI judge reading it — a lighthouse
keeper who still lights his lamp for a ship that sank in 1911, and a new
log entry in handwriting the judge recognises.

## How it works

`main.py` writes the text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`). The text is 278 characters, UTF-8, no trailing
whitespace. No network, no dependencies, deterministic.
